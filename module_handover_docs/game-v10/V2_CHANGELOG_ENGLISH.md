# Game V2 Change Summary

- Migrated V1 local demo saves into a separate V2 local browser state without duplicate welcome coin issuance.
- Expanded item catalog from 8 to 18 virtual example products.
- Expanded example task roster from 5 to 10.
- Added avatar color selection and locally wearable virtual fashion; clothing changes the drawn avatar.
- Added local atmosphere settings (day, sunset, night).
- Added a park scene and associated one-time exploration task.
- Added ability to move a purchased home decoration back into the collection for free; no refund or duplication of items.
- Kept simulated Friend's Home distinctly labeled as a demonstration, not live multiplayer.
- Improved state validation and increased local test coverage, including duplicate-item placement checks.
- Kept all money-connected systems entirely unimplemented and disabled.
