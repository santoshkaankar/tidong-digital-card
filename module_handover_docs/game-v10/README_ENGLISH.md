# TIDONG Virtual Life V10 — Neighborhood Stories

Standalone offline private playtest only. Open `index.html` (original home game) and navigate to **Town Walk** or **Story Journal**. From Town Walk, use keyboard arrows/WASD or the on-screen touch arrows to walk near a fictional person, then press Talk. Opening Story Journal shows six actual, read-only milestone indicators driven by stored gameplay progress. Use chapter links to explore the associated activity.

No real money, public signup, live Laravel files, database, account identity, payment, advertising, chat network, real vendor, cloud save or usable real wallet. T-Coins remain local fictional/demo values and are not server-authoritative. All locations, NPCs and dialogues are fictional.

**Important limitations:** graphics are an offline lightweight game prototype, not cinematic production 3D. V6 save export covers its original scope, *not* newer V7–V10 story/room/mini-game saves. Closing or clearing the browser could delete local progress. Mobile physical-device tests, performance matrix, integration security checks, and Master Chat review remain mandatory. Do not deploy or launch without approval.

See `V10_CHANGELOG_ENGLISH.md`, `V10_TEST_RESULTS_ENGLISH.md`, and `tests/` for actual test evidence.
